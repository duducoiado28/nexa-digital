# Nexa Digital

Aplicativo mobile desenvolvido com React Native e Expo para uma atividade acadêmica da FATEC.

## Funcionalidades

- Tela de login
- Tela inicial
- Tela Sobre
- Tela de contato
- Navegação entre as telas

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
